# M@t // Retro Phosphor CRT Terminal Portfolio

An interactive, retro CRT terminal portfolio and personal homepage for [Mátyás Szabó](https://github.com/matzy39sch), hosted on GitHub Pages.

Live at: **[matzy39sch.github.io](https://matzy39sch.github.io)**

---

## ⚡ Features

* **Retro CRT Aesthetics**: Vintage monitor bezel, customizable phosphor glow, subtle curved glare, CRT scanlines, and power-on degauss effects.
* **Multi-Color Phosphor Themes**:
  * 🟢 **P1 Green** (Classic IBM / VT100 phosphor)
  * 🟠 **P3 Amber** (VT220 phosphor)
  * 🔵 **Cyan** (Cyberpunk matrix)
  * ⚪ **Monochrome** (Paper white)
* **Zero-Dependency Sound Synthesizer**: Vintage keyboard keystrokes, bell chime, and CRT turn-on degauss sounds synthesized on the fly via the Web Audio API.
* **Interactive CLI**: After the boot narrative (or after pressing `SKIP`), visitors can use an interactive shell:
  * `help` - List all available commands
  * `about` - Bio, philosophy, and origin story
  * `skills` - Tech stack breakdown (Elixir, Erlang/OTP, Cloud APIs, IoT)
  * `projects` - Featured repositories & projects
  * `contact` - Direct contact links
  * `neofetch` - Retro ASCII system diagnostic summary
  * `joke` - Random developer and dad jokes
  * `theme [green|amber|cyan|white]` - Switch CRT colors
  * `sound [on|off]` - Toggle audio synthesis
  * `clear` - Clear terminal screen
  * `reboot` - Run power cycle and replay boot sequence
  * `sudo` - Privilege escalation easter egg
* **Pure Vanilla Web Stack**: Single-file, lightweight HTML5, modern CSS3 variables, and vanilla ES6+ JavaScript. No build steps, bundlers, or heavy dependencies required.
